================================================================================
                       PROJECT FUNCTIONS EXPLANATION
================================================================================

This document provides a comprehensive, file-by-file explanation of all the 
functions used across the React & Node.js Hotel Booking Application.

--------------------------------------------------------------------------------
1. FRONTEND API & UTILITY FUNCTIONS (Frontend/src/hotels.jsx)
--------------------------------------------------------------------------------

1. fetchHotelsApi()
   - Type: Asynchronous API Function (GET)
   - Description: Fetches the complete list of hotels from the backend database.
   - Endpoint: HTTP GET "http://localhost:5000/api/hotels"
   - Returns: Promise resolving to an array of hotel objects.

2. fetchHotelByIdApi(id)
   - Type: Asynchronous API Function (GET)
   - Description: Fetches details for a specific hotel by passing its unique ID.
   - Endpoint: HTTP GET "http://localhost:5000/api/hotels/:id"
   - Returns: Promise resolving to a single hotel object.

3. uploadImageApi(file)
   - Type: Asynchronous API Function (POST / Multipart Form)
   - Description: Takes an image file selected by the user, wraps it inside a 
     FormData object, and uploads it to the backend server.
   - Endpoint: HTTP POST "http://localhost:5000/api/upload"
   - Returns: The saved file path (e.g., "uploads/hotel-1700000000.jpg").

4. createHotelApi(hotelData)
   - Type: Asynchronous API Function (POST)
   - Description: Sends JSON-formatted hotel details to save a new hotel entry in PostgreSQL.
   - Endpoint: HTTP POST "http://localhost:5000/api/hotels"
   - Returns: The newly created hotel record returned from the backend.

5. updateHotelApi(id, hotelData)
   - Type: Asynchronous API Function (PUT)
   - Description: Sends updated hotel details as JSON to modify an existing hotel.
   - Endpoint: HTTP PUT "http://localhost:5000/api/hotels/:id"
   - Returns: The updated hotel record.

6. deleteHotelApi(id)
   - Type: Asynchronous API Function (DELETE)
   - Description: Requests deletion of a hotel record by its ID.
   - Endpoint: HTTP DELETE "http://localhost:5000/api/hotels/:id"
   - Returns: Confirmation message and deleted hotel ID.

7. getHotelImageSource(image)
   - Type: Utility Function
   - Description: Determines the correct URL string for displaying hotel images.
   - Logic: 
     * If image is empty -> returns default placeholder (/picture3.jpg)
     * If image starts with http://, https://, or data: -> returns as is
     * If image path starts with uploads/ -> prepends backend host (http://localhost:5000/)
     * Otherwise -> prepends '/' for local static assets.

8. getMapEmbedUrl(latitude, longitude)
   - Type: Utility Function
   - Description: Validates numerical latitude/longitude range and constructs an 
     OpenStreetMap embed URL for rendering an interactive location map.
   - Returns: OpenStreetMap embed URL string or null if coordinates are invalid.


--------------------------------------------------------------------------------
2. BACKEND SERVER & ROUTE FUNCTIONS (Backend/server.js)
--------------------------------------------------------------------------------

1. formatHotel(row)
   - Type: Helper Function
   - Description: Transforms raw database row objects from PostgreSQL queries into 
     frontend-friendly objects (e.g., converts numeric string coordinates into numbers).

2. Multer Storage Functions (destination, filename, fileFilter)
   - Type: Middleware Configuration Functions
   - Description: 
     * destination: Specifies the target folder ("Backend/uploads") for stored image files.
     * filename: Generates unique file names using timestamps to prevent name collisions.
     * fileFilter: Validates incoming files to ensure only image formats are saved.

3. app.get("/api/db-test", handler)
   - Type: Express Route Handler
   - Description: Executes "SELECT NOW()" to test if PostgreSQL database is connected.

4. app.post("/api/upload", handler)
   - Type: Express Route Handler
   - Description: Receives uploaded image file via Multer, saves it to disk, and 
     returns image path and full access URL.

5. app.get("/api/hotels", handler)
   - Type: Express Route Handler
   - Description: Queries all records from "hotels" table ordered by ID and returns JSON array.

6. app.get("/api/hotels/:id", handler)
   - Type: Express Route Handler
   - Description: Queries a specific hotel by ID, returning 404 if not found.

7. app.post("/api/hotels", handler)
   - Type: Express Route Handler
   - Description: Validates input fields and inserts a new hotel row into PostgreSQL database.

8. app.put("/api/hotels/:id", handler)
   - Type: Express Route Handler
   - Description: Updates an existing hotel's fields in PostgreSQL database using parameterized queries.

9. app.delete("/api/hotels/:id", handler)
   - Type: Express Route Handler
   - Description: Deletes hotel record matching the specified ID from PostgreSQL.


--------------------------------------------------------------------------------
3. FRONTEND CARD COMPONENT FUNCTIONS (Frontend/src/card.jsx)
--------------------------------------------------------------------------------

1. Card({ hotels, setHotels })
   - Type: React Functional Component
   - Description: Renders hotel cards with pagination, detail overlay, edit form, and delete button.

2. closeDetails()
   - Type: UI Handler Function
   - Description: Resets selected hotel and edit form states, closing the modal view.

3. saveHotel(event)
   - Type: Form Submission Handler (Async)
   - Description: Prevents default form submit, sanitizes form inputs, invokes 
     `updateHotelApi`, updates global hotel state, and closes edit form.

4. deleteHotel(hotelToDelete)
   - Type: Action Handler Function (Async)
   - Description: Displays a browser confirmation prompt, calls `deleteHotelApi`, 
     and filters out the deleted hotel from the UI state.


--------------------------------------------------------------------------------
4. FRONTEND ADD HOTEL COMPONENT FUNCTIONS (Frontend/src/addhotel.jsx)
--------------------------------------------------------------------------------

1. AddHotel({ onAddHotel })
   - Type: React Functional Component
   - Description: Form component allowing users to add a new hotel with live image preview.

2. updateHotel(event)
   - Type: Event Handler Function
   - Description: Dynamically updates state object properties as user types in form inputs.

3. uploadImage(event)
   - Type: File Input Handler Function
   - Description: Checks file type and 10MB size limit, creates a temporary preview URL 
     using `URL.createObjectURL(file)`, and updates component state.

4. submitHotel(event)
   - Type: Form Submission Handler (Async)
   - Description: Uploads image file via `uploadImageApi` if selected, formats price 
     currency, invokes `onAddHotel`, and redirects user to home page ("/") via `useNavigate`.
